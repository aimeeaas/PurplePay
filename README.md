## 💜 Purple Pay
Um aplicativo mobile desenvolvido com **React Native + Expo + SQLite**, voltado para o controle financeiro pessoal de forma simples, prática e organizada.

## Sobre o projeto
O Purple Pay permite que o usuário registre seus gastos, categorize despesas e acompanhe seus dados financeiros com facilidade.
A proposta é oferecer uma experiência intuitiva para organização financeira no dia a dia.

## Funcionalidades

✔ Cadastro de gastos <br>
✔ Edição de registros <br>
✔ Exclusão de despesas <br>
✔ Categorias pré-definidas <br>
✔ Filtro por mês e ano <br>
✔ Armazenamento local com SQLite <br>
✔ Interface simples e responsiva

## Tecnologias utilizadas

* React Native
* Expo
* Expo SQLite
* JavaScript

## Como executar o projeto

1. Clone o repositório
2. Instale as dependências: **npm install**
3. Execute o projeto: **npx expo start**
4. Instale o aplicativo Expo Go e Escaneie o QR Code exibido no terminal/navegador
- Android: *https://play.google.com/store/apps/details?id=host.exp.exponent*
- iOS: *https://apps.apple.com/app/expo-go/id982107779*
